Where your save is

In Finder press Cmd+Shift+G and paste this:

~/Library/Containers/com.rac7.SneakySasquatchMac/Data/Library/Application Support/com.rac7.SneakySasquatchMac/

Inside there are folders called default, default2 and default3. Those are your 3 save slots (slot 1, 2, 3). The files end in .stuff and they're just text (JSON), you can open them in TextEdit.

Important ones:
sasquatch.stuff - coins, day, which place you're in, hunger
variables.stuff - quest flags, speed limits and lots of other stuff
inventory.stuff - your items
map folder - one file per place

Back up your save

Quit the game. Go to the save folder, copy the slot folder (like default) and paste it somewhere safe like your Desktop. To go back, quit the game and put that copy back.

Put a ready-made save in

  1. Quit the game.
  2. Back up the slot you're going to use.
  3. Unzip the save. You get a folder called default.
  4. Rename it to the slot you want (default = slot 1, default2 = slot 2, default3 = slot 3).
  5. Drag it into the save folder and replace the old one.
  6. Open the game and load that slot.

Speed limit past the slider

When you're the mayor the speed limit slider only goes so far. But in variables.stuff the town limit is the key PD and the highway limit is Yt. Change those numbers to anything (even 999999 or negative) and the game uses it. The save editor does this for you. Changing mayor.stuff does nothing, that's just where the slider was.

Teleport anywhere

sasquatch.stuff has current_map, which is a long code for the place you're in. Change it to another place's code and you load in there. The save editor has a list of all the places so you don't need the codes. Some places act weird if you're not that far in the story yet.

Finish chapters

Each chapter being done is just a bunch of flags set to 1 in variables.stuff (in "flags"). The save editor has a checkbox for each chapter. This skips the story, so only do it on a save you don't care about.

Prison escape glitch

No save editing for this one, it works in the normal game. Your dog has to know enough tricks to do paw shake.

  1. Get the dog right up against the prison wall so its head clips through to your side.
  2. Do paw shake.
  3. The handshake moves you both into the handshake spot and doesn't check for walls, so you end up on the other side.

SSMod

SSMod adds stuff to a copy of the game instead of just changing your save. Get it on the downloads page. Mods are text files ending in .ssmod. Put them in SSMod's mods folder and double-click Install Mods.command. Want to make your own? Read the mod maker guide.
