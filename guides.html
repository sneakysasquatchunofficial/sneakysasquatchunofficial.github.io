Where your save is

In Finder, hit Cmd+Shift+G and paste this.

~/Library/Containers/com.rac7.SneakySasquatchMac/Data/Library/Application Support/com.rac7.SneakySasquatchMac/

The folders default, default2 and default3 are save slots 1, 2 and 3. Everything ending in .stuff is plain JSON. No encryption, TextEdit opens it fine.

The ones you'll care about. sasquatch.stuff has coins, the day, hunger and which scene you're in. variables.stuff has the quest flags and a pile of other settings, speed limits included. inventory.stuff is your items, and the map folder has one file per scene.

Backing up

Quit the game first. Then copy the slot folder, like default, somewhere safe. Restoring is the same thing backwards, again with the game closed. If the game is running it'll just write over whatever you put there.

Installing a save

  1. Quit the game.
  2. Back up the slot you're about to use.
  3. Unzip the save. You'll get a folder called default.
  4. Rename it for the slot you want, so default, default2 or default3.
  5. Drop it in the save folder and replace the old one.
  6. Start the game and load that slot.

Speed limit past the slider

As mayor you get a speed limit slider with a pretty small range. The actual values are in variables.stuff, though. PD is the town limit and Yt is the highway. The game takes whatever number you put there, 999999 or even negative, and doesn't clamp it. mayor.stuff only remembers where the slider was, so editing it does nothing. The save editor can set both.

Teleporting

In sasquatch.stuff, current_map is the ID of the scene you're in. It's a long hex string, not the scene name. Swap in another scene's ID and you load in there next time. The save editor has the full list so you don't have to dig the IDs out yourself. Expect weirdness if you jump somewhere the story hasn't unlocked yet.

Finishing chapters

A finished chapter is just a set of flags turned on in variables.stuff, under "flags". The game keeps a list of which flags belong to which chapter, and the save editor uses those lists. You skip the whole story this way, so do it on a save you don't mind ruining.

Prison escape glitch

This one's in the normal game, no editing needed. Your dog has to know paw shake.

  1. Push the dog up against the prison wall until its head clips through to your side.
  2. Do paw shake.

The handshake snaps both of you into fixed spots next to each other without checking for walls, so you get pulled straight through.

SSMod

SSMod works on a copy of the game instead of your save, so it can add things that don't exist at all, not just flip values. It's on the downloads page. Mods are plain text .ssmod files. Put them in SSMod's mods folder and run Install Mods.command. If you want to write one, start with the mod maker guide.
