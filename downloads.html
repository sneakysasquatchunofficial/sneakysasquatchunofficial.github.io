Sneaky Sasquatch (unofficial)

Downloads

Mac only, sorry. There are no game files in any of these, so you still need your own copy of the game. And please back up your save before trying anything (how). I've wrecked enough of mine to know.

SSMod

SSMod.zip (900 KB). My mod loader. It lets you add new places, characters, items, sounds and scripts to the game. It patches a copy of the app, so your normal install stays untouched. Start with START HERE.txt.

If you want to write your own mods, MOD-MAKER-GUIDE.txt is the gentle intro and SSMOD.txt is the full reference.

Mods

SSMod-Big-Mod-Pack.zip (1.8 MB). Everything bigger I've made so far: an airport, a zoo, a diner you can cook at, a pet cat that follows you around, taxes (I'm sorry), Ranger Pat, forest trails, Weather Wizard, Duck Lab and a few others. Needs SSMod.

Smaller example mods, one file each. These go in SSMod's mods folder:

  • sasquatch_powers.ssmod - three new powers on keys 1, 2, 3
  • race_the_clock.ssmod - timed race with a coach
  • hotdog_stand.ssmod - a hot dog vendor with a new item
  • corner_shop.ssmod - a small shop, good for learning the building commands
  • custom_meshes.ssmod - custom shapes from polygons or SVG
  • lpp_fan_club.ssmod - a sign that asks for a password

Save editor

The save editor handles coins, speed limits, finishing chapters and teleporting. It runs in the browser and doesn't upload anything.

Saves

MaxSave.zip. Day 1386, 999999 coins, chapters 1-4 done, most unlock flags set. Made on 2.2.1 for Mac. Installing it overwrites whatever is in that slot, so pick an empty one. Steps are here.

The mod guides page covers where saves live, the speed limit trick, teleporting and the prison glitch. There's also how-the-scenes-work.txt, my notes on how the game's scenes are put together.
