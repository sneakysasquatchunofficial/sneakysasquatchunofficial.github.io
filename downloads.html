Downloads

Mac only, sorry. There are no game files in any of these, so you still need your own copy of the game. And please back up your save before trying anything. Here's how. I've wrecked enough of mine to know.

SSMod

Download SSMod.zip 900 KB

My mod loader. It lets you add new places, characters, items, sounds and scripts to the game. It patches a copy of the app, so your normal install stays untouched. Start with START HERE.txt.

If you want to write your own mods, MOD-MAKER-GUIDE.txt is the gentle intro and SSMOD.txt is the full reference.

Mods

Download the Big Mod Pack 1.8 MB, needs SSMod

Everything bigger I've made so far. There's an airport, a zoo, a diner you can cook at, a pet cat that follows you around, Ranger Pat, forest trails, Weather Wizard, Duck Lab, a few others, and taxes. Sorry about that one.

Smaller example mods, one file each. These go in SSMod's mods folder.

  • sasquatch_powers.ssmod. Three new powers on keys 1, 2, 3
  • race_the_clock.ssmod. Timed race with a coach
  • hotdog_stand.ssmod. A hot dog vendor with a new item
  • corner_shop.ssmod. A small shop, good for learning the building commands
  • custom_meshes.ssmod. Custom shapes from polygons or SVG
  • lpp_fan_club.ssmod. A sign that asks for a password
