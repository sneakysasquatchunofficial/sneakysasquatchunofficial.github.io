Sneaky Sasquatch (unofficial)

This is a fan site for Sneaky Sasquatch. I've been exploring the Mac version of the game for quite some time—looking at saves, scenes, even attempting to build a mod loader—to organize some of the more useful information so others can find it.

The game

For those who haven't already: it is a game published by RAC7 Games in 2019 for Apple Arcade. It is available on Mac, iPhone, iPad, and Apple TV. The game features you as a sasquatch living near a campground, where for the first hour or so you primarily steal from picnic baskets as you are pursued by a park ranger.

From there, the game continues featuring disguises, various jobs, driving, fishing, golf, racing, a town, a seaport, and more—plus a story broken into chapters. I became interested in exploring the game in detail because it looks much smaller than it actually is.
